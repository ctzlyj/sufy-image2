# SUFY Image2 Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Repository instructions prohibit subagents.

**Goal:** Build and publish a portable Agent Skill that invokes LTS4AI `SF-gpt-image-2` for text-to-image, multi-reference editing, and bounded batch generation without persisting API keys.

**Architecture:** A single standard-library Python CLI owns URL normalization, request construction, response extraction, validation, retries, batching, and output persistence. `SKILL.md` gives Agents the minimal operating workflow, while focused reference documents hold the provider contract and troubleshooting details. Unit tests use a local HTTP server, so validation never consumes a real key or image quota.

**Tech Stack:** Agent Skills (`SKILL.md`, `agents/openai.yaml`), Python 3.10+ standard library, `unittest`, Git, GitHub CLI.
