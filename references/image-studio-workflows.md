# Image Studio 商品套图与服装工作台

本参考描述 `image.ctikki.com` 已验证的商品套图与服装工作台工作方式。使用本 Skill 独立调用模型时复用这些提示词规则；引导用户使用网站时遵守网站的账号、托管配置、任务和历史边界。

## 托管网站与独立 Skill 的边界

- 网站使用 LTS4AI 登录，邀请码机制与旧管理后台已移除；浏览器不得直接调用第三方模型或接触平台密钥。
- 网站使用服务端托管的 Base URL 和凭据；用户可通过“更换生图模型”选择 Flare、Sunburst 或原 Image2，默认 `SF-gpt-image-2.5-flare`。三种模型共享自定义厘米画布范围，选型说明使用本地中文对比图。
- 本 Skill 的 CLI 是独立调用方式，只接受用户自己的临时 `LTS4AI_API_KEY`，不得读取网站服务端密钥或复用客户登录状态。
- 登录后保留已填写内容，但不得自动重放生成请求；必须由用户再次确认执行。

## 商品套图

六类图片应形成连续购买路径，而不是六张重复主图：

| 图片 | 决策职责 |
|---|---|
| 主图 | 让用户看清商品，并理解一个核心购买理由 |
| 场景图 | 呈现谁在什么场景下如何使用，以及可见体验 |
| 卖点图 | 深入解释一个重点卖点，并给出视觉证据 |
| 白底图 | 标准、完整、无干扰地展示商品 |
| 认证图 | 为真实资质和品质保障提供版式，不虚构认证 |
| 四宫格图 | 补充材质、结构、工艺、步骤、真实差异或购买疑问 |

主图不是只能放一句话。围绕一个核心购买理由，可组织：

1. 1 条醒目的主标题。
2. 1 条解释用户价值的副标题。
3. 最多 2 个可信证据标签。

所有文字必须服务于同一主题，不能把三个平级卖点堆成口号墙。数字、参数、规格、倍率、效果、认证和对比结论，只能来自商品标题、参考图或用户明确提供的信息；无证据时减少文字，不得编造。商品必须是缩略图中的第一视觉焦点，同时完整保留商品本体文字、图案、结构和颜色。

场景图优先表现真实使用者、地点、动作与使用时刻。无法确认具体人群时，使用中性且符合品类常识的场景，不为“高级感”机械堆砌豪华环境。卖点图不得简单重复主图；四宫格每格只回答一个不同问题。

## 服装工作台

### 标准换装

标准换装先生成并审核主图，再基于审核通过的主图生成动作轮次：

1. 提供商品正面图，商品背面图可选但建议提供。
2. 选择内置模板、商户模板或本次上传的人物图。
3. 主图参考图顺序为商品图在前、人物模板在后：仅正面时为“图1商品正面、图2人物模板”；正反面齐全时为“图1商品正面、图2商品背面、图3人物模板”。
4. 主图必须仅换装，不改人，不改景，不改动作。保留人物身份、脸部、发型、妆容、体型、姿态、构图、镜头、光线和背景。
5. 严格还原服装版型、剪裁、领袖肩线、衣长腰线、颜色、面料、纹理、图案、褶皱、拼接、走线、纽扣、拉链、口袋、辅料和正反面结构。
6. 缺失正面或背面参考时，只能依据已确认的服装连续性保守还原，不得臆造新设计。
7. 用户完成主图审核后，才进入动作参考选择和动作图生成。

### 直接动作

直接动作跳过主图生成，直接从人物基准图生成 1–4 张动作图：

1. 图1是唯一动作与构图标准。
2. 图2是人物、服装和场景连续性基准。
3. 如提供商品图，图3为商品正面图，图4为商品背面图。
4. 只从图1继承姿态、身体朝向、手部位置、镜头角度、景别、留白与构图。
5. 从图2继承人物身份、脸部、发型、妆容、肤色、体型、服装、背景、光影和画面风格。
6. 没有商品图时，完整继承图2服装；有商品图时，使用图3和图4校验服装正反面细节。
7. 锁定图2背景，不增加配饰，不改变人物身份、服装款式、发型妆容或场景。

### 任务行为

- 内置模板只读；商户模板可以创建和删除。网站当前提供 16 组内置模板，标准换装默认使用模板封面，直接动作可选择同组 1–4 张动作参考图。
- 动作图以审核通过的主图维持人物与服装连续性；失败项按原动作参考重试，不改变成功结果。
- 支持取消、刷新恢复、部分失败、重试、预览、下载和删除；结果进入统一生图历史，不另建不可见历史。
- 网站中的文件、任务、模板和历史按商户隔离，图片交付及 COS 归档由网站管理；本 Skill 只保存本地输出，不操作网站历史、模板、COS 缓存或清理。归档失败不得变成新的付费生成请求。

## 调用建议

- 商品套图可把每种图片职责写成独立提示词，通过 `batch --prompts-file` 顺序生成。
- 服装任务必须使用 `edit` 或带参考图的 `batch`，并严格保持上述图片顺序。
- 先用 1K/2K 验证服装、人物和构图一致性，再按需要生成 4K；不要用放大掩盖换装错误。
- 每轮输出后实际查看图片，重点检查人物身份、手部、服装前后结构、图案位置、边缘、背景和动作是否符合参考。
